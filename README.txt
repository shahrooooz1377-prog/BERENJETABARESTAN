پروژه فول: فروشگاه برنج طبرستان حاج محمد یوسفی
امکانات:
  - ظاهر مدرن با Bootstrap (صفحات فارسی راست‌چین)
  - ثبت مشتری، نمایش جشنواره‌ها
  - پنل مدیریت ساده (ورود مدیر + داشبورد، افزودن جشنواره و FAQ، مشاهده مشتریان)
  - API ساده برای پاسخ به سوالات: POST /api/qa  body: {"question": "..."}

اجرا در ویندوز:
  1) اکسترکت کنید و در پوشه پروژه یک محیط مجازی بسازید و فعال کنید:
     python -m venv venv
     venv\Scripts\activate
  2) نصب وابستگی‌ها:
     pip install -r requirements.txt
  3) اجرا:
     uvicorn app.main:app --reload
  4) مرورگر:
     http://127.0.0.1:8000/

دسترسی پنل ادمین (پیش‌فرض):
  نام کاربری: admin
  رمز عبور: password123

هشدار امنیتی:
  این پنل مدیریت برای توسعه محلی طراحی شده است و از کوکی ساده برای احراز هویت استفاده می‌کند.
  برای استفاده در محیط واقعی حتماً احراز هویت امن، HTTPS و حفاظت CSRF را پیاده کنید.
